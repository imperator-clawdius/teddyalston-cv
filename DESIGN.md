# Portfolio Design Direction

## Goal

A technical recruiter should understand Teddy's target role, flagship system,
operating proof, and next action within 30 seconds.

## Positioning

Primary identity:

> Forward-Deployed AI Engineer

Primary promise:

> I turn messy business operations into bounded, auditable AI systems—from
> prototype through production.

Tax, commerce, and founder experience are supporting evidence of operating
judgment. They are not competing hero identities.

## Visual system

The direction is **enterprise cyberpunk**:

- retain the existing dark surface, grid, TA mark, and cyan/lime/pink accents;
- use neon as a signal, not a blanket effect;
- prefer real architecture, operating metrics, and project evidence over
  decorative graphics;
- use Barlow Condensed for display type and Inter for body/UI copy;
- keep the homepage on one base surface with lines and spacing before cards;
- use Bootstrap Icons for interface symbols; do not create one-off icon art.

## Content hierarchy

1. Role and operating outcome
2. Verified proof metrics
3. Trident Protocol
4. Argos Vendor Command
5. TraceReady
6. Deployment method
7. Operator context and core stack
8. Resume and contact
9. Extended project archive

## Proof policy

Only publish metrics that can be traced to a case study or operating record.
Do not turn total repository count into a homepage success metric.

## Responsive behavior

- Desktop uses a persistent dossier rail.
- Mobile uses one compact sticky header and a native disclosure menu.
- The role and Trident action must appear before branding artwork.
- Primary actions must remain keyboard reachable and at least 44 pixels high.
